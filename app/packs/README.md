# キャラクターパックの作り方

基本の画像 1 枚から、familiar で動くパックを作る手順。形式の仕様は [`docs/character-pack.md`](../../docs/character-pack.md)。
絵を使わずコードだけで描く例は `generate_default.py`。

## 始める前に
- **権利を確かめる。** 配布するなら、元絵の権利、画像・動画モデルの利用条件、特定の作家の画風を指定していないかを確認する。個人で使うパックも、リポジトリにはコミットしない
- **元絵の条件。** 背景が単色、キャラの周りを線が囲んでいる、顔と手（または手に当たる部分）がはっきりしている。下が切れた絵でもよい（切れ目を画面の下端に合わせる）。人間である必要はない
- **費用の目安。** 基準絵 9 枚と動画 16 本で約 $9（1 回の成功例。試行の失敗で増える）
- **道具。** 画像編集モデルと、始点・終点を指定できる動画モデル、ffmpeg、Node

## 1. 5 つのポーズを決める
アプリは意味だけを知っている。見た目はキャラごとに決めてよい。

| ハブ | 意味 | 作り方の例 |
|---|---|---|
| F 正面 | 平常時。元絵そのまま | 背景だけ単色へ差し替える |
| B 背面 | 背を向ける | F から真後ろの姿を生成 |
| T 考え中 | 見回りの最中 | F から、あごに指を当てるなどに編集 |
| I ひらめき | 新しい提案を見つけた | T から、指を立てるなどに編集 |
| Q 耳を傾ける | 返事を待つ | F から、頭だけ少し傾ける |

閉じ目の絵（F、T、Q）も用意する。F 以外は画像編集で作り、頭の高さ、大きさ、下の切れ目を F と揃える。

- 手は拡大し、肩 → 肘 → 手首 → 見える面の順にたどって確かめる
- 描きにくいポーズに固執しない。2 回外したら、同じ意味の定番の形へ替える
- 仕草は小さく。常駐キャラは小さな動きで足りる

**ここで全部を確認してから動画に進む。** 動画より基準絵のほうが直しやすい。

## 2. クリップを作る
全 20 本。[始点, 終点] のハブを動画モデルの先頭と末尾のコマに指定する（1 本 3 秒程度）。

| クリップ | 始点 → 終点 | 内容 |
|---|---|---|
| `idle_f` / `idle_b` | F → F / B → B | 小さな待機 |
| `look` | F → F | 周りを見る |
| `stretch` | F → F | 伸び。上げる動画を生成し、下ろしは逆再生でよい |
| `turn_away` / `turn_back` | F → B / B → F | 振り向く。戻りは逆再生でよい |
| `think_in` / `think_out` | F → T / T → F | 考え始める、やめる |
| `think_a` / `think_b` | T → T | 考え中のループ 2 種 |
| `idea` | T → I | 閃く。前半で動作を終え、残りは静止 |
| `idea_out` | I → F | 閃きから平常へ |
| `idea_ask` | I → Q | 閃いたあと、返事を待つ |
| `ask_in` | F → Q | 声をかけ直す |
| `ask_wait` | Q → Q | 返事を待つループ |
| `ask_ok` | Q → F | うなずく（全部に返事があった） |
| `ask_out` | Q → F | 待つのをやめる |
| `blink` / `blink_t` / `blink_q` | F / T / Q | 閉じ目の目元だけを貼る、短いクリップ（9 コマほど） |

全クリップの指示に、次を入れる。
- 背景は完全に平らな単色で、影も光も粒子もない
- カメラは固定で、キャラは同じ場所、同じ大きさ。下端で同じ高さに切れる
- 遷移は動かす部位だけを書き、「体はその場に残る」と書く

**先に `turn_away` と `idle_f` の 2 本だけ作る。** 背景が保たれ、キャラが崩れないことを見てから残りを作る。

## 3. 透過にして、端をハブへ揃える
- 背景色をキーで抜き、線で囲まれた外側だけを透明にする
- 各クリップの両端の数コマ（9 コマほど）を、余弦カーブで基準絵へ寄せる。これで継ぎ目が消える
- 色は乗算済みにする

## 4. 書き出す
左半分に色、右半分にアルファ（白 = 不透明）を並べ、H.264、24fps、`yuv420p` で書き出す。ffmpeg の例は `generate_default.py` の `render()`。

`clips.json` に、クリップごとの総コマ数、秒、絵が変わるコマ番号を書く。

```
~/.local/share/familiar/packs/<id>/clips/
  clips.json
  blink.mp4 ...
```

## 5. 検査して使う
```sh
node app/qa_graph.mjs ~/.local/share/familiar/packs/<id>
```

全クリップが揃い、遷移に問題がなければ `OK` と出る。`~/.local/state/familiar/config.json` に `"character": "<id>"` を足して、アプリを再起動する。パックが壊れていると、アプリは同梱のデフォルトで起動する。

最後に実際の動きを目で見る。間と勢いは数字では分からない。
