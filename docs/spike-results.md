# P0 スパイク結果

実施: 2026-10-31（土）/ Claude Code 2.1.316 / 実行: `spikes/scan-once.sh`

## 結論
launchd から起動した `claude -p` で、読み取り専用の見回りが提案 JSON を返すところまで動いた。
ただし企画書 3.1 のコマンドのままでは読み取り専用にならないため、下の形に変えた。

## S1: launchd とコネクタ
- launchd 起動（環境変数 14 個）でも、通常のシェルと同じ 117 個のコネクタツールが読み込まれた。認証も通る
- launchd の `PATH` に `~/.local/bin` がないため、`claude` は絶対パスで呼ぶ
- 許可リストは `prompts/allowed-tools.txt`、拒否リストは `prompts/denied-tools.txt`

### 見回りの権限
| 指定 | 理由 |
|---|---|
| `--permission-mode dontAsk` | ユーザー設定が `defaultMode: auto` のため、指定しないと許可リスト外のツールも自動承認されうる。これで許可リスト外は拒否になる |
| `--disallowedTools <書き込みツール全部と無関係なサーバー>` | `--allowedTools` だけでは他のツールは見えたまま残る。これで一覧からも消える |
| `--tools ToolSearch` | 組み込みツールを無効にする。MCP ツールの読み込みに ToolSearch だけ要る |
| `--setting-sources user` + `--settings '{"disableAllHooks":true}'` | `--setting-sources ""` だとコネクタまで消える。設定は読み、hook だけ止める |

確認した内容:
- 初期化時のツール一覧に、書き込みツールは含まれない（許可した読み取りツール、ToolSearch、StructuredOutput のみ）
- 許可リストにも拒否リストにも載せなかった無害な `notion-get-self` を呼ばせると、`dontAsk` により拒否された。実際の書き込みは試していない
- `--max-turns` はヘルプに載っていないが有効

注意: コネクタに新しい書き込みツールが増えると拒否リストから漏れ、一覧には見えるようになる。その場合も `dontAsk` で拒否される。
本実装では実行前後に許可リストとの照合を行う。初期化イベントだけでは足りない。
MCP サーバーが `pending` のまま初期化が終わると、そのツールは一覧に載らず、後から現れる（Slack で実際に発生。23 個と 31 個の差が出た）。
そのため照合は、全サーバーが接続済みになった時点の一覧か、実際の呼び出し履歴に対して行う。

リストは接続先が増えたら作り直す。全 269 ツールのうち許可 34、拒否 235（名前に書き込み系の語を含むものは許可側に 0 件）。

## S2: 出力の安定性・所要時間・使用量
| 実行 | モデル | 期間 | 所要 | 換算コスト | 提案 |
|---|---|---|---|---|---|
| 手動 | Sonnet | 24 時間 | 11 秒 | $0.136 | 0 件 |
| 手動 | Haiku | 24 時間 | 11 秒 | $0.009 | 0 件 |
| launchd | Haiku | 24 時間 | 11 秒 | $0.006 | 0 件 |
| 手動 | Sonnet | 7 日 | 30 秒 | $0.167 | 3 件 |
| 手動 | Haiku | 7 日 | 23 秒 | $0.010 | 2 件 |
| 手動（6 情報源） | Sonnet | 7 日 | 26 秒 | $0.252 | 2 件 |
| 手動（6 情報源） | Haiku | 7 日 | 44 秒 | $0.016 | 2 件 |

- 全実行で最終的に schema どおりの `structured_output` が返った。Haiku は 1 回、JSON の不正で再試行した。回数が少なく、安定の証明としては弱い
- `dedupe_key` は一部のみ安定。OpenAI のメールは一致したが、CI 失敗は Sonnet が `github:…`、Haiku が `gmail:…` を付けた。**モデルに作らせず、steward 側で出典 URL から正規化する**
- 提案の範囲はモデルで異なる。Sonnet は本文を 3 通読み、CI 失敗を拾った。Haiku は本文を 1 通しか読まず、CI 失敗を拾わなかった
- 平日 9–20 時・30 分間隔（1 日 22 回）の単純計算で、Gmail と Notion だけの場合は Sonnet 約 $3/日、Haiku 約 $0.2/日。6 情報源（7 日分の実行）の単価なら Sonnet 約 $5.5/日、Haiku 約 $0.35/日。サブスクの枠をどれだけ消費するかは未測定
- 2 段構えを採る（判断の詳細は企画書 3.1）

### `coverage` を追加
当初の出力では「何もなかった」と「読めなかった」を区別できなかった。
情報源ごとの `coverage`（ok / partial / failed）を schema に加えた。
