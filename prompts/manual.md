# familiar の使い方
ユーザーに familiar の機能や設定を聞かれたときに答える元です。機能や設定を変えたら、このファイルも直します。

## できること
- 身の回り（既定は Slack・Gmail・Google Calendar・Notion・GitHub・Linear）を見回り、タスクにした方がよさそうなことを提案する
- 提案を採用すると、計画とタスクの定義（背景・やること・達成条件・確かめ方）を示す。承認すると、その内容で実行する（既定は Linear に issue を作る）
- 採用した提案は見回りで追い、進んだ・返事待ち・止まっている・終わったといった変化があれば会話で知らせる
- 会話では相談に乗り、指示ファイルの変更案を出す。会話から外へ書き込むことはない。外への書き込みは、提案を採用して承認したときだけ
- Mac が起きている間だけ働く

## 提案への操作
- 採用: 計画づくりが始まる。計画を見て「進める」で実行、「やり直す」で計画し直す。質問が来たら会話で答える
- 済ませた: 委ねるまでもなく自分で片付けたとき。役に立った提案として記憶される
- 却下: 要らないとき。理由を添えると次からの判断に使う。1 回の却下で、その種類すべてを止めはしない。種類ごと止めたいときは「知らせ方」に書く
- 「これについて話す」で、その提案に結び付けて相談できる。話した内容は計画に使われる
- 見回りと会話は出した提案も見直し、終わったものや不要なものは理由を付けて取り下げ、古い内容は更新する。取り下げは会話で頼めば戻せる

## 見回りの頻度
設定画面の「見回り」で決める。
- 既定は平日の 9 時から 20 時まで 30 分ごと
- 「時刻」にすると、決めた時刻に見回る（例: `8:00, 13:00`）。スリープで逃したときは、戻ったときに 1 回見回る
- どちらも曜日を選べる。人と会う予定の前後の見回りは止められる

## 会話
- ホットキー（既定は `⌃⌥Space`）で開く。もう一度押すか、× や Esc で閉じる。ホットキーは設定画面で変えられる
- 返事を待つ間も話しかけられる。言葉は送った順に 1 つずつ返事をする。提案への操作はそれぞれ別に進む
- 判断を待つ提案と指示の変更案は、入力欄の上の棚に残る
- 設定画面は会話の ⚙︎ から開く。会話を閉じたあと約 10 秒は、キャラクターの右クリックから設定と終了を選べる

## 声
設定画面の「音声」で、OpenAI 互換のサーバを音声認識と音声合成のそれぞれに指定する（任意）。
- 音声認識を指定すると、入力欄の横にマイクのボタンが出る。「一括」は止めたときにまとめて文字にし、「リアルタイム」は話しながら文字にする
- 音声合成を指定すると返事を読み上げる。「読み上げない」で止められる

## 指示と記憶
`~/.local/state/familiar/workspace/` の Markdown が全ての記憶。変更は差分を見て `反映` を押すと保存される。
- SOUL.md: 人格と振る舞い
- HEARTBEAT.md: 見回りで確認すること。「知らせ方」の節に、知らせてほしいこと・知らせなくてよいことを書く
- OUTPUT.md: 採用時にすること。守りたい方針もここ
- USER.md: 好み、関係者、進行中の仕事
- MEMORY.md: 判断の基準など長く使う事実
- memory/YYYY-MM-DD.md: 採用・却下・自分で済ませたことと、話した言葉
- DREAMS.md: 記憶を整理した記録

判断が 3 件以上たまると、1 日 1 回 USER.md と MEMORY.md へ整理する。同じ訂正が繰り返されたら、HEARTBEAT.md か OUTPUT.md の変更案を会話に出す。

## 仕事を預ける先: collie
collie はユーザーの手元の道具で、無人の Claude Code セッションに仕事をさせる。`OUTPUT.md` に collie の手順が書かれているときだけ使う。
- 預け方: 承認のときに「任せる」「やっておいて」のように実行まで任せると、Linear ではなく collie に積む（`collie task add`）。「今すぐ」と言えばすぐ始まり、言わなければ collie の時間帯・離席・使用量の条件がそろったときに始まる
- collie がすること: タスクごとに作業用のチェックアウト（git worktree と `collie/<タスク ID>` ブランチ）を作り、herdr のペインで Claude Code を起動して、渡した内容のとおりに作業させる。コードの仕事に限らず、調べ物や報告書づくりもできる
- 状態: queued（まだ）→ running（作業中）→ review（終わって人の確認待ち）→ done（確認済み）。blocked は質問か権限の確認で止まっている。failed は失敗
- 見届け: 預けたものの結果は `collie:<タスク ID>` になる。見回りが `collie task show` で状態と報告を読み、変化があれば会話で知らせる。blocked は返事待ち、failed は停滞として伝える
- 人がすること: 質問に答える、結果を確かめて done にする、失敗をやり直す。collie の画面（`collie tui`）か、herdr のそのペインで行う。ブランチをマージすると自動で done になる
- Linear からも入る: `collie` ラベルが付き自分が担当の issue は、collie が 5 分ごとに取り込む。始まると issue のステータスが動くが、終わっても Linear へは書き戻さない
- 会話から collie に積んだり、操作したりはしない。状態を読むことはできる

## herdr と Claude Code
- herdr: AI エージェントのセッションを並べて動かす端末の道具。collie のタスクは herdr のペインで動き、止まると herdr の通知が出る。ユーザーはそのペインに入って様子を見たり答えたりできる
- Claude Code: 実際に作業するエージェント。collie のセッションの中身のほか、familiar の見回り・会話・実行も Claude Code（`~/.local/bin/claude`）で動いている

## その他
- 権限は Claude Code の設定と許可済みの MCP に従う。familiar 側では制限しない
- キャラクターはパックで差し替えられる（`~/.local/share/familiar/packs/`）
- そのほかの設定は `~/.local/state/familiar/config.json`（例: `linearTeam`、`character`）
- 会話と実行の記録は `~/.local/state/familiar/` に残る（`runs/` は 14 日間）
- 新しい版は自動で入る。起動の 1 分後と 6 時間ごとに確かめ、会話と設定を閉じて 2 分触らなかったときに再起動する
